## 🔐 AUTHENTICATION & ROLE GUARDS (CRITICAL)
### Shared guard module
Create:
```
/src/utils/guards.js
```
### Required functions
- `requireAuth(redirectTo="/auth/login.html")`
- `requireRole(allowedRoles, redirectTo="/auth/login.html")`
- Optional helper: `routeAfterLogin(role)`
### Behavior
- No session → redirect to login
- Wrong role → redirect to correct dashboard or `/index.html`
### Data source
- Auth: `supabase.auth.getSession()`
- Role: `profiles.role` (Supabase table)
